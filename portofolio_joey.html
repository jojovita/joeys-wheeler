Tentang Saya

Halo! Saya Joey, seorang profesional di bidang IT dengan fokus kuat pada pengembangan web dan infrastruktur jaringan. Saya memiliki ketertarikan mendalam pada teknologi dan selalu bersemangat mempelajari hal-hal baru.

Ketika saya tidak sedang coding atau mengkonfigurasi server, Anda mungkin akan menemukan saya sedang memainkan alat musik, mencari harmoni baik dalam baris kode maupun nada lagu.
